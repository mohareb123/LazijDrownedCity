لعبة عالم مفتوح منخفض التفاصيل بواجهة عربية: عنكبوت آلي مترابط وبطل بشري أصلي قابلان للتبديل، مدينة 2.46 × 2.46 كم من 6403 مبانٍ، تسلق وتأرجح، حملة تنتهي بقتال زعيم وسباق أسطح.

## مرحلة القتال والتقدم v1.7
اندفاعة خيط X، مراوغة R، تحذير قبل ضربات الأعداء، ضربات J متتابعة، و3 دوريات بموجتين وخبرة محفوظة ترفع سعة التركيز. اقترب من علامة دورية خضراء واضغط N. ليست هذه لعبة AAA مكتملة؛ المحتوى الجديد مرحلة محدودة قابلة للعب.

[التفاصيل والاختبارات والحدود وخارطة الطريق](PROGRESS-v1.7.md)

## تحديث العالم v1.6

[تفاصيل العالم والفيزياء والاختبارات والحدود](WORLD-v1.6.md)

## التحكم
WASD حركة · Shift جري · Space قفز · E تثبيت خيط (إمساك وإفلات) · Shift أثناء التثبيت لسحب الخيط · Tab خريطة · Q تسلق · Q+S نزول · C تبديل الشخصية · F شبكة هجومية · J ضربة قريبة · R دحرجة · T رقصة · M سباق · V منظور · ESC إيقاف.

اجمع 8 قطع من النول، اصعد البرج الأوسط، واضرب الزعيم 3 ضربات تفصل بينها مهلة قصيرة. بعد النهاية يمكنك استكشاف المدينة وجمع القطع المتبقية.

## التشغيل المحلي
من جذر المستودع:
```sh
python3 -m http.server 8080
```
افتح http://localhost:8080. جميع النماذج محلية؛ لا يحتاج التشغيل إلى شبكة بعد تنزيل المستودع كاملًا.

## إعادة البناء والاختبار
```sh
python3 build_open.py
cp open-world.html index.html
python3 gen_harness.py
node harness_openworld.mjs
bash pc/build_exe.sh
```
حزمة Windows داخل LazijCity-win64.zip؛ استخرجها كاملة ثم شغّل LazijCity.exe.
